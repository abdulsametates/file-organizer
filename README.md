# 📁 Modern File Organizer & Cleaner

A sleek, lightweight, and modern desktop application built with Python and CustomTkinter to automatically organize your files and clean up messy file names.

---

## ✨ Features

* **Smart Categorization:** Automatically sorts your files into specific folders (*Images, PDF and Documents, Archives, Code, Videos and Music, Installation Files, Other Files*).
* **File Name Cleaner:** Automatically cleans unwanted underscores (`_`) and hyphens (`-`) from file names, making them neat and readable.
* **Duplicate Protection:** Prevents file overwriting by safely appending a numbered suffix (e.g., `file (1).ext`) if a duplicate name exists.
* **Modern GUI:** Designed with a clean, eye-friendly, and modern macOS-inspired interface using CustomTkinter.

---

## 🛠️ Built With

* **Python**
* **CustomTkinter** (Modern UI library)
* **OS & Shutil** (File management)
* **Tkinter** (Dialogs and file pickers)

---

## 🚀 How to Use

1. Download the latest `.exe` version from the `dist` folder.
2. Run the application.
3. Click **Select Folder** and choose the directory you want to organize.
4. Click **Organize Now** and watch your files get cleaned and sorted instantly!
